# LANHOUSE.GG rulebooks

The rulebook of every tournament run on [LANHOUSE.GG](https://lanhouse.gg), kept here so anyone can check what the rules said, and when.

- One folder per tournament: `tournaments/<slug>/RULEBOOK.md`.
- The platform commits here automatically every time an organizer changes the rules, the key dates or the format. Nobody edits these files by hand.
- The commit history is the audit trail: open a file and press **History** to see every version and what changed between them.

Other public records for each tournament:

- **Transparency page** on LANHOUSE.GG (`/t/<slug>/transparency`): version history, registration ledger, bracket versions, integrity decisions and prize payouts.
- **Google Sheet** linked from that page: registrations, the hash-chained ledger and every published bracket, read-only for everyone.
